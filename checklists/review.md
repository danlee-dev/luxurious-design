# 내보내기 전 점검표

실제 크기로 렌더링한 이미지를 띄워 놓고 확인합니다. 수치나 코드만 보고 체크하지 않습니다.

## 용도

- [ ] 누가 이 작업물을 보고 무엇을 하게 되는지 한 문장으로 말할 수 있습니다.
- [ ] 그 문장과 맞지 않는 장이나 요소가 없습니다.

## 위계

- [ ] 화면마다 주인공이 하나입니다.
- [ ] 손톱 크기로 줄여도 주인공이 가장 먼저 보입니다.
- [ ] 글자 크기가 세 단계 안에 들어갑니다.
- [ ] 같은 역할의 요소는 크기, 굵기, 색이 같습니다.

## 서체

- [ ] 서체가 두 종을 넘지 않습니다.
- [ ] 두 서체 모두 고른 이유를 말할 수 있습니다. 도구의 기본 서체가 아닙니다.
- [ ] 큰 제목의 서체와 굵기를 실제 문장으로 만든 서체판에서 골랐습니다. 본문용 서체의 Black을 제목 크기로 키우지 않았습니다.
- [ ] 날짜, 시간, 통계 숫자가 디스플레이 서체로 통일되어 있습니다.
- [ ] 제목의 줄바꿈이 의미 단위에서 끊깁니다. 마지막 줄에 한두 글자만 남지 않습니다.
- [ ] 가장 작은 글자가 실제 보는 환경에서 읽힙니다.

## 배치

- [ ] 모든 요소의 왼쪽 끝이 그리드 열 시작선에 있습니다.
- [ ] 세로 시작선이 네 개를 넘지 않습니다.
- [ ] 위 여백과 아래 여백이 같습니다.
- [ ] 묶음 사이 간격이 묶음 안 간격의 두 배 이상입니다.
- [ ] 간격 값이 정해 둔 단계 안에 있습니다.
- [ ] 큰 글자의 잉크 경계가 다른 요소와 맞습니다.
- [ ] 겹치거나 닿는 글자가 없습니다.

## 색

- [ ] 강조색이 하나입니다.
- [ ] 강조색이 한 화면에서 한 곳에만 쓰였습니다.
- [ ] 어두운 색에 파란 기운이 없습니다.
- [ ] 본문 글자의 대비가 4.5 : 1 이상, 큰 글자가 3 : 1 이상입니다. 실제 바탕색 기준으로 쟀습니다.
- [ ] 어두운 화면의 본문이 순백이 아닙니다.

## 사진

- [ ] 사진이 창이나 띠로 잘려 있지 않습니다.
- [ ] 피사체가 구성상 필요한 자리에 있습니다.
- [ ] 글자가 놓인 곳이 충분히 어둡거나 고릅니다.
- [ ] 컷아웃 가장자리에 배경색 테두리가 없습니다. 사진에 없는 색 위에서 확인했습니다.
- [ ] 그림자와 글자의 빛이 사진 속 광원과 같은 방향입니다.
- [ ] 피사체가 글자를 가려도 단어가 읽힙니다. 처음 보는 사람에게 확인했습니다.
- [ ] 캡처 속 작은 숫자를 키운 확대 원이 다른 숫자나 후기 문장을 가리지 않고, 원 안 숫자 폭이 지름의 80% 이하입니다.
- [ ] 사진의 사용 권리를 확인했습니다.

## 기본값 신호

- [ ] 그라디언트가 장식으로 쓰이지 않았습니다.
- [ ] 가운데 정렬이 이유 없이 쓰이지 않았습니다.
- [ ] 범용 아이콘과 이모지가 없습니다.
- [ ] 둥근 카드 상자가 반복되지 않습니다.
- [ ] 파스텔 원 안의 아이콘, 왼쪽 색 막대, 장식용 상태 점이 없습니다.
- [ ] 넓은 자간의 장식용 영문이 없습니다.
- [ ] 어느 행사에 붙여도 말이 되는 문장이 없습니다.
- [ ] 구분선이 간격으로 대신할 수 있는 곳에 쓰이지 않았습니다.
- [ ] 기기와 화면이 정면으로 놓였습니다. 기울였다면 그 장의 생각을 보여 주는 하나뿐이고, 각도가 망설임 없이 큽니다.
- [ ] 겹친 카드에 2D 회전이 없습니다.
- [ ] 기기 이미지 둘레에 잘린 그림자 경계가 없습니다.
- [ ] 첫 장이나 표지의 배경에 실제 물체가 있습니다. UI 카드만 쌓은 배경이 아닙니다.
- [ ] 렌더나 사진의 배경과 슬라이드 바탕 사이에 경계가 보이지 않습니다.
- [ ] 오린 인물의 어깨에 세로 경계가, 아래 끝에 가로 경계가 남지 않았습니다.
- [ ] 여러 인물 사진의 얼굴 폭과 얼굴 위끝 높이가 같습니다.

## 내용

- [ ] 모든 줄이 정보를 담고 있습니다. 지워도 전달되는 정보가 줄지 않는 줄이 없습니다.
- [ ] 날짜, 시간, 범위 기호의 표기가 전체에서 같습니다.
- [ ] 내부에서만 통하는 이름과 줄임말이 없습니다.
- [ ] 확정되지 않은 내용에 표시가 있습니다.
- [ ] 수치에 기준과 기간이 붙어 있습니다.
- [ ] 인용한 말의 출처를 확인했습니다.
- [ ] 밖으로 나가는 자료에 내부 정보가 없습니다.
- [ ] 데이터로 뒷받침되지 않는 숫자를 써넣지 않았습니다. 다른 기준으로 센 숫자는 기준을 표기했습니다.
- [ ] 심사위원이나 고객이 받는 부록에 목차 장, 질문형 제목, 내부 메모가 없습니다.
- [ ] 사업 발표 자료의 제목이 사업 계획서에 옮겨 적을 수 있는 문장입니다. 구어체 훅이 아닙니다.

## 여러 장짜리 작업

- [ ] 모든 장을 한 화면에 늘어놓고 확인했습니다.
- [ ] 로고, 쪽 번호, 제목의 위치가 장마다 같습니다.
- [ ] 모든 장에 제품 로고(심볼과 워드마크)와 회사 마크가 있고, 장마다 렌더에서 로고 주변을 잘라 확대해 보이는지 확인했습니다.
- [ ] 내용의 아랫변이 같은 기준선에 닿습니다.
- [ ] 한 장이 한 가지만 말합니다.
- [ ] 같은 종류의 정보가 같은 형태로 표현되어 있습니다.
- [ ] 일정이 있는 장에서 항목의 길이가 보입니다.
- [ ] 새 디자인은 버전 섹션에 따로 두었고, 덱 줄의 원본을 덮어쓰지 않았습니다.

## 과정

- [ ] 기준으로 삼은 실제 작업이 있고, 가져온 기법을 이름으로 말할 수 있습니다.
- [ ] 시안 이름에 가져온 레퍼런스의 구도가 적혀 있고, 레퍼런스 옆에 놓았을 때 이미지 자리, 제목 크기와 굵기, 작은 정보 자리, 카드 분포가 같습니다.
- [ ] 받은 피드백을 다시 읽고, 말한 그대로 반영됐는지 확인했습니다.
- [ ] 100퍼센트 크기와 축소한 크기, 두 가지로 확인했습니다.
