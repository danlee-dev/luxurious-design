# 07. 컨셉

디자인이 막힐 때는 대개 배치가 아니라 말할 것이 없는 상태입니다. 컨셉은 제목, 한 줄 설명, 공간 이름, 대표 이미지가 모두 같은 말을 하게 만드는 한 단어입니다. 행사에도, 제품 출시에도, 보고서 표지에도 같은 방식으로 씁니다.

## 관찰한 패턴

해마다 주제를 바꿔 여는 한 창업 경진대회의 최근 다섯 해를 살펴봤습니다. 공개된 보도자료와 기사 기준입니다.

| 연도 | 주제어 |
| --- | --- |
| 2022 | Be Doers |
| 2023 | 불굴 (Tenacity) |
| 2024 | RISK TAKER (모험가) |
| 2025 | 개척 (Frontier) |
| 2026 | 무한 (Infinite) |

해마다 단어는 바뀌지만 쓰는 방식은 같았습니다.

| 요소 | 방식 |
| --- | --- |
| 주제어 | 두 언어를 나란히 적습니다. 다섯 해 가운데 세 해는 한글 두 글자에 영문 한 단어를 붙였고, 두 해는 영문 구가 주였습니다. 한쪽이 주가 되고 다른 쪽이 풀이가 됩니다 |
| 출처 | 조직이 원래 가진 자산에서 가져옵니다. 이 대회는 설립자의 어록에서 단어를 뽑았습니다 |
| 한 줄 설명 | "[주제어에 해당하는 행동을 하는] 사람들의 무대" 꼴의 문장 하나 |
| 기조연설 | 제목에 주제어를 넣습니다 |
| 공간 이름 | 주제어를 앞에 붙입니다. 교류 공간, 전시 부스의 이름이 주제어로 시작합니다 |
| 시각 모티프 | 해마다 실물 하나를 정해 대표 이미지로 씁니다 |
| 상 이름 | 대상, 최우수상 같은 표준 이름을 그대로 둡니다 |

마지막 줄이 중요합니다. 주제어를 모든 곳에 붙이지 않습니다. 사람들이 이미 아는 이름이 필요한 곳은 그대로 둡니다.

## 만드는 순서

1. 이 조직이나 제품이 실제로 하는 행동을 동사로 적습니다. 만들다, 내보내다, 건너다, 쌓다 같은 것입니다.
2. 그 동사를 대표하는 단어 하나를 고릅니다. 기준은 아래 표에 있습니다.
3. 다른 언어로 짝을 붙입니다. 영문이 주면 한글 두 글자를, 한글이 주면 영문 한 단어를 붙입니다.
4. 단어를 풀이하는 문장 하나를 씁니다. 누가, 무엇을 하는 자리인지가 들어갑니다.
5. 단어에서 바로 떠오르는 실물 하나를 정합니다. 사진으로 구할 수 있는 것이어야 합니다.
6. 어디에 적용하고 어디에 적용하지 않을지 표로 정합니다.

## 단어를 고르는 기준

| 기준 | 확인 방법 |
| --- | --- |
| 짧습니다 | 영문은 네 글자에서 여덟 글자, 한글은 두 글자가 다루기 좋습니다. 표지에서 크게 쓸 수 있어야 합니다 |
| 조직 안에서 이미 쓰는 말입니다 | 구성원이 평소에 쓰는 단어면 설명 없이 받아들여집니다 |
| 밖에서도 뜻이 통합니다 | 처음 듣는 사람이 한 번에 뜻을 아는지 확인합니다. 내부에서만 통하는 줄임말이나 별칭은 쓰지 않습니다 |
| 행동이 들어 있습니다 | 상태를 나타내는 명사보다 하는 일을 나타내는 단어가 한 줄 설명을 쓰기 쉽습니다 |
| 뜻이 두 겹입니다 | 일상의 뜻과 업계의 뜻이 겹치는 단어는 실물 모티프를 찾기 쉽습니다 |
| 글자 모양이 좋습니다 | 크게 썼을 때 획의 리듬이 고른지 디스플레이 서체로 미리 써 봅니다 |

## 어록에서 가져올 때

유명한 사람의 말에서 단어를 가져오는 것은 흔한 방법이지만 두 가지를 지킵니다.

- 원문과 출처를 확인합니다. 널리 퍼진 인용 가운데에는 출처가 확인되지 않는 것이 많습니다. 확인되지 않으면 쓰지 않습니다.
- 조직과 관계가 있는 사람의 말을 씁니다. 관계없는 유명인의 말은 어느 조직에 붙여도 말이 되므로 컨셉이 되지 못합니다.

## 적용 범위

| 적용합니다 | 적용하지 않습니다 |
| --- | --- |
| 표지의 주인공 단어 | 상 이름, 직함 |
| 한 줄 설명 | 시간표의 항목 이름 (접수, 휴식) |
| 대표 이미지의 사물 | 안내 문구, 신청 양식의 질문 |
| 공간과 세션 이름 한두 개 | 본문 문장마다 |

한 줄 설명은 한 번만 씁니다. 장마다 같은 문장을 되풀이하거나 비슷한 문장을 덧붙이지 않습니다.

## 시각으로 옮기기

- 주제어가 표지의 주인공이 됩니다. 가장 크게, 디스플레이 서체로 씁니다.
- 실물 모티프는 실제 사진으로 씁니다. 아이콘이나 그림으로 바꾸면 클립아트가 됩니다.
- 강조색 하나를 주제어의 짝이 되는 단어나 사진 속 빛에 씁니다.
- 주제어, 사물, 색이 하나씩이면 충분합니다. 두 번째 모티프를 더하지 않습니다.

## 확인 질문

- 주제어를 빼고 한 줄 설명만 읽어도 무슨 자리인지 알 수 있습니까.
- 같은 주제어를 다른 조직이 써도 어색하지 않다면, 이 조직만의 근거가 무엇입니까.
- 사물 하나만 보여 줘도 주제어가 떠오릅니까.
- 내년에 단어만 바꿔 같은 틀을 다시 쓸 수 있습니까.
