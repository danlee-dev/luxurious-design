# 참고 자료

이 저장소의 내용을 정리하면서 실제로 찾아본 자료입니다. 주제별 검색에서 나온 글들이며, 대부분 실무 블로그와 대학 가이드입니다. 연구 논문이 아니므로 구체적인 수치는 경험칙으로 다룹니다.

링크는 2026년 11월에 열리는 것을 확인한 것만 달았습니다. 자동 접근을 막아 확인하지 못한 자료는 이름만 적었습니다. 1차 문헌 가운데 직접 열람하지 않은 것은 따로 표시했습니다.
