# 10. 사례: 표지 한 장의 다섯 단계

행사 소개 자료의 표지 한 장이 통과되기까지의 과정입니다. 행사와 조직의 이름은 뺐고, 같은 단계에서 함께 만든 곁가지 시안은 생략했습니다. 조건은 다음과 같았습니다.

| 항목 | 내용 |
| --- | --- |
| 화면 | 1920×1080 |
| 주제어 | 영문 대문자 네 글자와 한글 두 글자 |
| 모티프 | 주제어에서 나온 사물 하나 |
| 바탕 | 조직이 원래 쓰던 검은 배경과 강조색 하나 |
| 요청 | 눈에 띄고, 세련되고, 깔끔할 것 |

## 1단계: 글자 하나를 사물 그림으로 바꿈

주제어의 글자 하나를 로고에서 가져온 사물 그림으로 대체했습니다. 나머지는 검은 바탕에 흰 글자였습니다.

- 평가: "AI 같다."
- 원인: 평면적인 사물 그림이 굵은 글자의 획과 맞지 않았고, 글자를 사물로 바꾸는 발상 자체가 생성 결과물에서 흔한 것이었습니다. 바탕이 비어 있어 깊이도 없었습니다.
- 이후: 바로 고치지 않고 방법론부터 조사했습니다. 시선 경로, 그리드, 주인공과 위계, 색의 절제, 기본값으로 읽히는 신호를 찾아 정리했고, 그 내용이 이 저장소의 [01](01-principles.md), [02](02-ai-look.md), [04](04-layout-and-flow.md)입니다.

## 2단계: 사진을 창 모양으로 넣음

조사한 내용을 따라 12단 그리드와 머리띠를 세우고, 사물 그림 대신 실제 사진을 썼습니다. 사진은 화면 한쪽의 창 안에 넣었습니다.

- 평가: "잘리는 게 별로다." 이어서 "배경이 있었으면 좋겠는데 왜 또 자르느냐."
- 원인: 창 밖의 영역은 여전히 빈 바탕이었고, 사진의 피사체는 창 가장자리에서 끊겼습니다.
- 배운 것: "잘린다"는 말을 창의 모양 문제로 해석하면 안 됩니다. 자르지 말라는 뜻입니다.

## 3단계: 사진을 전면에 깖

같은 사진을 화면 전체에 깔았습니다. 사진을 화면보다 크게 놓고 피사체가 주인공 단어 근처에 오도록 위치를 잡았습니다. 위쪽은 그라디언트로 어둡게 해 머리띠 정보가 읽히게 했습니다.

- 평가: 방향은 통과했습니다. 다만 한글이 "AI 같다"는 평을 받았습니다.
- 원인: 한글이 도구의 기본 고딕이었습니다.

## 4단계: 한글 서체를 바꿈

실제 표지 문구로 한글 서체 후보 판을 만들어 나란히 놓고 골랐습니다. 굵은 라틴 디스플레이 서체 옆에서 밀리지 않는 명조 계열 서체가 선택됐습니다. 배치는 그대로 두고 서체만 바꿨습니다.

- 평가: 통과했습니다. 다만 주인공 단어 자체에도 디자인이 들어갔으면 좋겠다는 요청이 있었습니다.
- 배운 것: 배치가 같아도 서체 하나로 인상이 바뀝니다. 서체는 맨 처음에 정해야 합니다.

## 5단계: 주인공 단어를 피사체 뒤에 둠

글자에 효과를 더하는 대신 글자와 사진의 관계를 바꿨습니다.

- 사진에서 피사체만 남긴 컷아웃을 만들어 글자 위에 올렸습니다. 피사체가 글자 사이를 가립니다.
- 컷아웃에 넓고 부드러운 그림자를 걸어 피사체가 글자 앞에 있다는 것을 분명히 했습니다.
- 글자 채움을 흰색에서 강조색으로 가는 그라디언트로 두고, 사진 속 광원이 있는 아래쪽이 물들게 했습니다.
- 평가: 통과했습니다.

1단계에서 글자 자리에 사물을 둔 것과 5단계에서 피사체가 글자 사이에 선 것은 발상이 비슷합니다. 달라진 것은 사물이 실제 사진이라는 점, 사진이 화면 전체에 깔려 글자와 같은 공간에 있다는 점, 빛과 그림자가 글자와 맞물린다는 점입니다.

## 최종 구성

| 요소 | 위치와 크기 | 서체 |
| --- | --- | --- |
| 사진 | 화면보다 2.4배 넓게, 전면 | |
| 위쪽 어둡게 하는 그라디언트 | 머리띠가 놓이는 위쪽 | |
| 머리띠 | 로고 왼쪽 위, 정보 세 칸을 3, 6, 9번 열에, 아래에 가는 선 | 한글 Medium 24 안팎 |
| 주인공 단어 | 왼쪽 여백선에서 시작, 크기 690 | 라틴 디스플레이 Black |
| 피사체 컷아웃 | 사진과 같은 위치와 크기, 그림자 흐림 48, 불투명도 55퍼센트 | |
| 한글 주제어 | 오른쪽 열, 크기 68, 강조색 | 한글 Bold |
| 한 줄 설명 | 주제어 아래 두 줄 | 한글 Medium |
| 날짜 | 오른쪽 열, 크기 112 | 라틴 디스플레이 Black |
| 요일과 시각 | 날짜 아래 작게 | 한글 Medium |

시선은 왼쪽 위 로고에서 시작해 머리띠를 지나, 가운데의 주인공 단어와 피사체에 머문 뒤, 오른쪽 열의 주제어와 날짜에서 끝납니다. 강조색은 로고의 작은 표식을 빼면 한글 주제어와 글자 아래쪽의 빛, 두 곳에만 있고 둘 다 사진 속 불빛과 같은 계열입니다.

## 정리

| 반려 사유 | 실제 원인 | 고친 방법 |
| --- | --- | --- |
| AI 같다 (1단계) | 클립아트 사물, 빈 바탕 | 방법론 조사 후 실제 사진으로 교체 |
| 잘린다 (2단계) | 사진을 창에 가둠 | 사진을 전면에 깖 |
| AI 같다 (3단계) | 기본 한글 고딕 | 후보 판에서 서체를 다시 고름 |
| 단어에도 디자인이 들어갔으면 (4단계) | 글자와 사진이 따로 있음 | 글자를 피사체 뒤에 두고 빛과 그림자를 맞춤 |

네 번의 수정 가운데 효과를 더한 것은 한 번도 없습니다. 모두 기본값을 걷어 내거나 요소 사이의 관계를 바꾼 것이었습니다.
