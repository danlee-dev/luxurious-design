# 05. 색과 어두운 화면

## 강조색은 하나, 한 화면에 한 곳

색을 많이 쓸수록 어느 것도 강조되지 않습니다. 바탕은 무채색으로 두고 강조색 하나만 씁니다.

- 강조색은 그 화면에서 가장 먼저 보여야 하는 한 곳에 씁니다. 주제어 하나, 숫자 하나, 현재 단계 하나입니다.
- 같은 화면에서 강조색이 네 군데에 보이면 그것은 강조가 아니라 무늬입니다.
- 상태를 나타내는 색(오류, 완료)은 강조색과 별개로 실제 상태가 있을 때만 씁니다.
- 큰 면적에 색을 쓰고 싶으면 색면 하나를 화면의 절반 가까이 크게 씁니다. 작은 색 조각을 여러 곳에 흩지 않습니다.

공개된 사례입니다.

| 사례 | 색을 다루는 방식 |
| --- | --- |
| Vercel의 브랜드와 Ship 행사 | 검정과 흰색이 바탕이고, 서체와 간격이 인상을 만듭니다. 외부 분석들은 흑백 아이덴티티가 미완성으로 읽힐 위험을 타이포그래피와 여백이 메운다고 정리합니다. 행사 연도마다 입자, 금속 질감 같은 모티프 하나를 얹습니다 |
| NASA 그래픽 표준 매뉴얼 (1976) | 로고타입 하나와 정해진 서체로 편지지부터 기체까지 통일했습니다. 간결한 표준화가 통일성과 정밀함을 전한다는 평가를 받았습니다 |
| 인쇄 수업의 2도 과제 | 잉크 두 가지만 쓰고 검정도 한 색으로 셉니다. 제약이 위계를 타이포그래피로 풀게 만듭니다 |

## 어두운 화면의 글자색

검은 바탕에 순백 글자는 대비가 가장 높지만 오래 보기에 편하지 않습니다. 밝은 글자의 가장자리가 번져 보이는 현상이 생기고, 난시가 있는 사람에게 더 심합니다. 그래서 어두운 화면 가이드들은 공통으로 두 가지를 권합니다.

1. 바탕은 순흑 대신 아주 어두운 회색으로 둡니다. #121212가 기준값으로 자주 인용됩니다.
2. 본문은 순백 대신 밝은 회색으로 둡니다. #E0E0E0에서 #D4D4D4 사이, 또는 흰색 87퍼센트가 권장값입니다. 순백은 제목과 가장 강한 강조에만 씁니다.

대비의 하한은 웹 접근성 지침(WCAG 2.x)을 따릅니다.

| 대상 | 최소 대비 |
| --- | --- |
| 본문 크기의 글자 | 4.5 : 1 |
| 큰 글자, 아이콘과 입력란 테두리 같은 화면 요소 | 3 : 1 |

바탕 #121212 위에서 계산한 값입니다.

| 글자색 | 대비 | 쓰임 |
| --- | --- | --- |
| #FFFFFF | 18.7 : 1 | 제목, 큰 숫자 |
| #EDEDED | 16.0 : 1 | 본문 |
| #E0E0E0 | 14.2 : 1 | 본문 |
| #D4D4D4 | 12.6 : 1 | 본문 |
| #A3A3A3 | 7.4 : 1 | 설명, 라벨 |
| #8A8A8A | 5.4 : 1 | 라벨. 본문 크기에서 쓸 수 있는 가장 어두운 쪽 |
| #737373 | 4.0 : 1 | 큰 글자에만. 본문에는 쓰지 않습니다 |
| #595959 | 2.7 : 1 | 글자에는 쓰지 않습니다. 선이나 비활성 표시에만 |

단계는 세 개면 충분합니다. 제목은 순백, 본문은 밝은 회색, 보조 정보는 중간 회색입니다.

대비를 직접 계산할 때 쓰는 식입니다.

```python
def luminance(hex_color):
    def channel(c):
        c /= 255
        return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    h = hex_color.lstrip("#")
    r, g, b = (int(h[i:i + 2], 16) for i in (0, 2, 4))
    return 0.2126 * channel(r) + 0.7152 * channel(g) + 0.0722 * channel(b)

def contrast(a, b):
    hi, lo = sorted((luminance(a), luminance(b)), reverse=True)
    return (hi + 0.05) / (lo + 0.05)

print(round(contrast("#E0E0E0", "#121212"), 1))  # 14.2
```

대비는 순흑이 아니라 실제 바탕색을 기준으로 잽니다. 사진이나 밝은 면 위에 글자를 얹으면 값이 달라집니다.

## 중성 회색

어두운 색에 파란 기운을 넣으면 기본 다크 테마처럼 읽힙니다. 색 온도를 줄 이유가 없으면 R, G, B 값이 같은 회색을 씁니다.

| 단계 | 예시 값 |
| --- | --- |
| 바탕 | #0A0A0A ~ #121212 |
| 올라온 면 | #171717 |
| 선, 경계 | #262626 |

밝은 회색 쪽도 같습니다. 본문과 보조 정보의 회색에 색을 섞지 않습니다.

## 사진 위의 글자

- 글자가 놓이는 쪽에만 어둡게 하는 층을 얹습니다. 검정에 가까운 색을 40~60퍼센트로 덮거나, 글자 쪽에서 진하고 반대쪽에서 투명해지는 그라디언트를 씁니다.
- 대비는 글자 아래에서 가장 밝은 지점을 기준으로 확인합니다.
- 사진 전체를 똑같이 어둡게 덮으면 사진이 죽습니다. 주인공 피사체 쪽은 덮지 않습니다.
- 별이나 입자처럼 잔무늬가 많은 배경 위에서는 작은 글자가 무늬와 섞입니다. 본문이 있는 장은 더 진하게 덮습니다.

## 강조색을 어두운 바탕에 쓸 때

- 채도가 높은 강조색은 큰 글자와 숫자에 씁니다. 작은 본문을 강조색으로 쓰려면 4.5 : 1을 넘는지 확인합니다. 예를 들어 호박색 #E5A23C는 #121212 위에서 8.5 : 1입니다.
- 강조색 글자와 순백 글자가 한 줄에 있으면 순백이 더 밝아 먼저 읽힙니다. 강조하려는 쪽의 크기나 굵기를 함께 올립니다.

## 그라디언트

그라디언트는 근거가 있을 때만 씁니다.

| 쓰는 경우 | 쓰지 않는 경우 |
| --- | --- |
| 사진 위 글자를 읽히게 하려고 한쪽을 어둡게 할 때 | 배경을 채우려고 두 색을 섞을 때 |
| 사진 속 광원 쪽으로 글자가 물드는 것을 표현할 때 ([06](06-photo-and-depth.md)) | 글자를 화려하게 만들려고 할 때 |
