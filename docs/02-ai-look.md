# 02. AI처럼 보이는 신호와 대신 할 것

"AI가 만든 것 같다"는 평은 대부분 "기본값으로 만든 것 같다"는 뜻입니다. 생성 모델은 학습 데이터에서 가장 흔한 형태로 수렴하고, "깔끔하고 모던하게" 같은 막연한 요청은 그 수렴을 더 강하게 만듭니다. 사람이 템플릿을 그대로 써도 같은 인상이 납니다. 조사한 글 가운데에는 이런 신호가 AI의 특징이 아니라 기본값의 특징이라고 정리한 것도 있습니다.

따라서 고칠 것은 도구가 아니라 기본값입니다. 아래 표는 실제 반려 사유와 조사에서 반복해서 나온 신호를 모은 것입니다.

## 신호와 대안

| 신호 | 그렇게 읽히는 이유 | 대신 할 것 |
| --- | --- | --- |
| 도구가 처음 띄우는 서체 (라틴은 Inter, 한글은 기본 고딕) | 모든 도구와 템플릿의 기본값이라 고른 흔적이 없습니다 | 디스플레이 서체와 한글 서체를 후보 판에서 비교해 고릅니다 ([03](03-typography.md)) |
| 보라와 파랑 그라디언트 배경, 그라디언트 글자 | 생성 결과물의 첫 화면에서 가장 흔한 조합입니다 | 무채색 바탕에 강조색 하나. 그라디언트는 사진 속 빛을 표현할 때만 씁니다 ([05](05-color-and-dark.md)) |
| 모든 요소 가운데 정렬 | 가운데 제목, 버튼 두 개, 카드 세 장으로 이어지는 뼈대가 반복됩니다 | 왼쪽 시작선을 공유하는 비대칭 배치. 가운데 정렬은 이유가 있는 한 요소에만 씁니다 ([04](04-layout-and-flow.md)) |
| 범용 아이콘, 이모지 아이콘 | 내용과 무관하게 어디에나 붙는 그림입니다 | 아이콘 자리에 숫자, 단어, 실제 사진을 둡니다. 없어도 읽히면 뺍니다 |
| 둥근 카드의 반복 (반투명 배경, 색 있는 테두리) | 정보를 상자에 담아 나열하는 가장 쉬운 구성입니다 | 상자를 걷어 내고 간격과 정렬로 묶습니다. 구분이 꼭 필요하면 가는 선 하나를 씁니다 |
| 글자 하나를 클립아트풍 사물로 바꾸기 | 사물의 그림체와 글자의 획이 맞지 않아 합성한 티가 납니다 | 글자를 그대로 두거나, 실제 사진의 피사체를 글자와 겹치고 빛과 그림자를 맞춥니다 ([06](06-photo-and-depth.md)) |
| 넓은 자간의 작은 영문 대문자를 장식으로 쓰기 | 읽을 내용이 없는 글자입니다 | 같은 자리에 날짜, 장소, 규모 같은 사실을 일정한 표기로 넣습니다 |
| 파스텔 원 안에 같은 색 아이콘 | 기능 목록 템플릿의 표준 형태입니다 | 썸네일이나 단색 타일을 씁니다. 색은 상태를 나타낼 때만 씁니다 |
| 선택 항목 왼쪽의 색 세로 막대 | 대시보드 템플릿의 표준 형태입니다 | 굵기와 명도 대비로 현재 항목을 구분합니다 |
| 사진을 창이나 띠 모양으로 잘라 넣기 | 사진이 잘려 보이고 배경과 따로 놉니다 | 사진을 화면 전체에 깔고 글자를 그 위나 뒤에 둡니다 ([06](06-photo-and-depth.md)) |
| 채움용 태그라인과 영문 슬로건 | 어느 행사에 붙여도 말이 되는 문장입니다 | 문장을 빼거나, 주제어를 풀이하는 한 줄만 둡니다 ([07](07-concept.md)) |
| 파란 기운이 도는 어두운 배경 | 기본 다크 테마의 색입니다 | R, G, B 값이 같은 중성 회색을 씁니다 ([05](05-color-and-dark.md)) |
| 유리 효과, 네온 발광, 입자 장식 | 내용과 무관하게 얹는 효과입니다 | 효과를 쓰려면 사진 속 광원처럼 근거가 있는 곳에만 씁니다 |
| 상태 점, 깜빡이는 표시, LIVE 배지를 장식으로 쓰기 | 실제 상태가 없는데 상태처럼 보입니다 | 실제 상태가 있을 때만 정적인 표시로 씁니다 |
| 크기 차이가 작은 제목과 본문 | 무엇이 중요한지 정하지 않은 화면입니다 | 주인공을 다음 단계의 몇 배로 키웁니다 ([01](01-principles.md)) |
| 구분선을 항목마다 긋기 | 간격으로 할 일을 선으로 하고 있습니다 | 묶음 사이 간격을 묶음 안 간격의 두 배 이상으로 둡니다 |
| 흑백 단체 사진, 스톡 일러스트, 점토 질감 3D 사물 | 소재 사이트에서 가장 많이 쓰이는 그림입니다 | 내용에서 직접 나온 사물 하나를 실제 사진으로 구합니다 |
| 이미 쓴 카드뉴스나 템플릿의 부품을 다시 조합하기 | 외곽선 글자, 사선, 격자, 얇은 선 일러스트가 익숙한 조합으로 보입니다 | 실제 디자이너의 작업 한두 개를 기준으로 삼아 새로 짭니다 ([09](09-process.md)) |
| 기기와 화면을 어중간하게 기울인 3D 배치 | 고급 효과를 흉내 낸 기본값으로 읽히고, 각도가 서로 달라 시선이 흩어집니다 | 정면으로 두고 겹침과 크기로 깊이를 만듭니다. 기울기는 장면 하나가 생각을 보여 줄 때만 크게 한 번 씁니다 ([06](06-photo-and-depth.md)) |

## 기본값에서 벗어나는 순서

1. 서체를 바꿉니다. 조사한 글들이 가장 먼저 꼽는 신호가 기본 서체입니다.
2. 색을 무채색과 강조색 하나로 줄입니다.
3. 모서리 반경과 카드 상자를 걷어 냅니다.
4. 정렬을 가운데에서 왼쪽 시작선으로 옮깁니다.
5. 주인공의 크기를 키워 위계를 다시 세웁니다.
6. 장식을 실제 정보로 바꿉니다.

앞의 세 가지만 바꿔도 인상이 크게 달라집니다.

## 판단에 쓰는 질문

- 로고를 가려도 누구의 작업인지 짐작할 수 있습니까. 다른 로고를 붙여도 말이 되면 기본값입니다.
- 이 서체, 이 색, 이 사진을 고른 이유를 한 문장으로 말할 수 있습니까.
- 이 요소를 지우면 전달되는 정보가 줄어듭니까.
- 참고한 실제 작업이 있고, 거기서 가져온 기법의 이름을 댈 수 있습니까.

## AI 도구에 요청할 때

막연한 형용사 대신 구체적인 제약을 줍니다.

| 막연한 요청 | 구체적인 제약 |
| --- | --- |
| 세련되고 고급스럽게 | 서체 두 종의 이름, 굵기, 크기 단계 |
| 깔끔한 레이아웃 | 화면 크기, 여백, 열 수, 요소별 시작 열 |
| 눈에 띄게 | 주인공으로 삼을 요소 하나와 그 크기 |
| 트렌디하게 | 기준으로 삼을 실제 작업 한두 개와 가져올 기법 |
| AI 같지 않게 | 위 표에서 금지할 항목의 목록 |

결과를 받은 뒤에는 실제 크기로 렌더링한 이미지를 직접 보고 판단합니다. 코드나 수치만 보고 통과시키지 않습니다.
