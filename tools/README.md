# tools

## cutout.py

어두운 배경 위의 밝은 피사체를 투명 PNG로 분리합니다. 글자를 피사체 뒤에 두는 합성([06. 사진과 깊이](../docs/06-photo-and-depth.md))에 쓸 컷아웃을 편집 프로그램 없이 만들 때 씁니다.

### 준비

Python 3과 Pillow가 필요합니다.

```bash
python3 -m pip install Pillow
```

### 사용

```bash
python3 tools/cutout.py photo.png subject.png --seed 1610,900 --preview check.png
```

| 인자 | 기본값 | 설명 |
| --- | --- | --- |
| `input` | | 원본 사진 |
| `output` | | 저장할 투명 PNG |
| `--seed X,Y` | 필수 | 피사체의 밝은 부분 위 한 점. 원본 좌표입니다. 떨어진 덩어리마다 하나씩 여러 번 줍니다 |
| `--bg-seed X,Y` | 위쪽 세 점과 좌우 가운데 | 배경의 어두운 부분 위 한 점 |
| `--threshold` | 76 | 밝은 곳과 어두운 곳을 나누는 밝기 (0~255) |
| `--soft LO,HI` | 62,128 | 가장자리 반투명 구간. LO 이하는 투명, HI 이상은 불투명 |
| `--scale` | 0.5 | 영역을 찾을 때 쓰는 작업 배율 |
| `--edge` | 7 | 반투명 가장자리를 허용할 범위. 작업 배율 기준 픽셀, 홀수 |
| `--hole` | 9 | 피사체에 넣을 어두운 구멍을 찾는 범위. 작업 배율 기준 픽셀, 홀수 |
| `--feather` | 1.1 | 최종 알파를 흐리는 반경. 원본 기준 픽셀 |
| `--preview` | | 단색 배경에 얹은 확인용 이미지 경로 |
| `--preview-bg` | #FF00C8 | 확인용 배경색 |

씨앗 좌표는 이미지 편집기나 미리보기 프로그램에서 피사체 위에 커서를 올려 읽습니다.

### 동작

1. 픽셀 밝기를 R, G, B 중 최댓값으로 구하고, 작업 배율로 줄여 살짝 흐립니다.
2. 임계값으로 밝은 곳과 어두운 곳을 나눕니다.
3. 배경 씨앗에서 이어진 어두운 영역을 배경으로 표시합니다.
4. 피사체 씨앗에서 이어진 밝은 영역을 피사체로 표시합니다. 배경에 떨어져 있는 밝은 점은 여기서 빠집니다.
5. 피사체에 붙어 있고 배경과 이어지지 않은 어두운 부분을 피사체에 넣습니다. 피사체 안의 그늘과 어두운 무늬가 뚫리지 않습니다.
6. 피사체 가장자리 근처에서는 밝기에 비례한 반투명을 줍니다. 연기나 빛 번짐이 부드럽게 남습니다.
7. 알파를 원본 크기로 되돌리고 약하게 흐려 저장합니다.

### 결과 조정

| 증상 | 조정 |
| --- | --- |
| 배경의 밝은 부분이 딸려 옵니다 | `--threshold`를 올립니다. `--soft`의 LO도 함께 올립니다 |
| 피사체의 어두운 쪽이 깎입니다 | `--threshold`를 내립니다 |
| 피사체의 일부 덩어리가 빠집니다 | 그 덩어리 위에 `--seed`를 하나 더 줍니다 |
| 가장자리에 뿌연 테두리가 남습니다 | `--soft`의 LO를 올리거나 `--edge`를 줄입니다 |
| 가장자리가 종이를 오린 것처럼 딱딱합니다 | `--soft`의 구간을 넓히거나 `--feather`를 올립니다 |
| 피사체 안에 구멍이 뚫립니다 | `--hole`을 키웁니다 |
| "씨앗이 임계값보다 어둡습니다" 경고 | 씨앗을 더 밝은 지점으로 옮기거나 `--threshold`를 내립니다 |

확인용 이미지는 사진에 없는 색 위에 결과를 얹은 것입니다. 가장자리에 원래 배경색이 얇게 남아 있으면 여기서 보입니다. 그다음 실제 구성에 넣어 100퍼센트 크기로 가장자리를 한 번 더 봅니다.

### 한계

- 피사체가 배경보다 확실히 밝아야 합니다. 밤하늘 앞의 조명 받은 사물, 검은 배경의 제품 사진 같은 경우입니다.
- 밝은 배경 앞의 어두운 피사체, 배경과 밝기가 비슷한 피사체에는 맞지 않습니다. 이런 사진은 피사체 자동 선택 기능이 있는 편집 도구를 씁니다.
- 피사체와 맞닿은 밝은 배경 요소는 한 덩어리로 잡힙니다. 임계값으로 떼어지지 않으면 손으로 지워야 합니다.
- 머리카락처럼 아주 가는 구조는 정밀하게 남지 않습니다.
- 3240×1350 사진에서 5초 안팎이 걸립니다.

### 합성에 넣을 때

컷아웃은 원본 사진과 크기가 같습니다. 디자인 도구에서 사진을 담은 사각형을 복제하고 이미지만 컷아웃으로 바꾸면 위치와 배율이 그대로 맞습니다. 글자 레이어를 두 사각형 사이에 둡니다.
